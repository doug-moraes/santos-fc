# Projeto Santos FC ⚪🖤

Projeto web desenvolvido como iniciativa pessoal com o objetivo de praticar e aprimorar habilidades de desenvolvimento front-end, focando na estruturação, estilização e criação de uma interface dedicada ao **Santos Futebol Clube**.

---

## 🚀 Sobre o Projeto
O site consiste em uma página informativa/landing page inspirada no Santos FC, apresentando elementos visuais marcantes da história do clube, imagens relacionadas à torcida e um layout responsivo focado no ecossistema santista.

## 🛠️ Tecnologias Utilizadas
* **HTML5:** Estruturação semântica do conteúdo e das seções da página.
* **CSS3:** Estilização visual, regras de layout e identidade do clube.
* **Mídia & Ativos:** Otimização e organização de imagens do Santos FC e sua torcida.

## 📁 Estrutura de Pastas
* `index.html`: Página principal e estrutura central do projeto.
* `style.css`: Arquivo de estilização e folha de estilo global.
* `santos.png`: Escudo/emblema oficial e ativos visuais do clube.
* `toricidavila.jpeg`: Imagem temática da torcida na Vila Belmiro.
